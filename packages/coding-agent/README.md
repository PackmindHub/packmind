# coding-agent

This library was generated with [Nx](https://nx.dev).

Renders and deploys Packmind artifacts (standards, commands, skills) into the file layout expected
by supported AI coding agents (Claude, Cursor, Copilot, and others).

## Building

Run `nx build coding-agent` to build the library.

## Running unit tests

Run `nx test coding-agent` to execute the unit tests via [Jest](https://jestjs.io).
