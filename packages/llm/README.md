# llm

This library was generated with [Nx](https://nx.dev).

Provider-agnostic access to large language models: it wraps OpenAI, Anthropic, Gemini, Azure OpenAI and Packmind's own service behind a single factory (`createLLMService`) and a common `AIService` interface.

## Building

Run `nx build llm` to build the library.

## Running unit tests

Run `nx test llm` to execute the unit tests via [Jest](https://jestjs.io).
