# migrations

This library was generated with [Nx](https://nx.dev). It holds the TypeORM migrations for the Packmind database schema — see the `how-to-write-typeorm-migrations-in-packmind` skill for how to write and run them.

## Building

Run `nx bundle migrations` to build the library.

## Running unit tests

Run `nx test migrations` to execute the unit tests via [Jest](https://jestjs.io).

## Running migrations

Run `nx run migrations:run` to apply pending migrations against the Docker datasource.
