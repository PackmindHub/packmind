# node-utils

This library was generated with [Nx](https://nx.dev).

It is Packmind's shared backend framework, providing base classes (`BaseHexa`, `HexaRegistry`), scoped repositories, and infrastructure helpers such as `Configuration.getConfig()` — the sanctioned way to read secrets/config — plus caching, jobs, SSE, and mail.

## Building

Run `nx build node-utils` to build the library.

## Running unit tests

Run `nx test node-utils` to execute the unit tests via [Jest](https://jestjs.io).
