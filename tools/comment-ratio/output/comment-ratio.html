How it is measured

Method and limits

Every line of a file goes into exactly one bucket — blank, code, or comment — and the ratio is then comments over non-blank lines:

comment ratio = comment lines comment lines + code lines

Blank lines count neither in the numerator nor in the denominator. A line is a comment only when every non-whitespace character on it belongs to one: const a = 1; // why is therefore code. That is the convention cloc uses.

Two sets of lines feed into it, and that is the only difference between the report's two measures. The flow takes the lines added during a period; the stock takes every line of every file at a date. Worked on the 1 Sept → 15 Sept 26 period, which you can find in the table above:

17.9% = 6,276 6,276 + 28,799
  • Comments are located with the official TypeScript parser rather than a regular expression, so strings, template literals, regex literals and JSX text containing // are not mistaken for comments. The JSX idiom {'{/* ... */}'} counts as a comment, on every line it spans.
  • .d.ts files are excluded. Renames are detected, so moving a file does not look like new code.
  • The repository's public history starts on 5 September 2025 with an import of an already existing codebase. That first delta is not a period of development and is left out of the charts.
  • The trailer records the model of the session that produced a commit, not necessarily the author of every line in it. Pull requests are squashed on merge, so one trailer covers one pull request.
  • Commits from 18 September 2026 onwards are excluded (--until 2026-09-18): a deliberate comment-rewriting pass landed that day, and it would have accounted for nearly half of the final period's added comment lines while removing far more.
  • A modified line reaches git as a removal plus an addition, so "added lines" includes rewrites. The ratio answers "when this code was written, what share was comment", not "how much net documentation was produced".
  • Commits with no trailer (most of 2025) are of unknown attribution, not "human".
